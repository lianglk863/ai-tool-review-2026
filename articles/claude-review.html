📝 产品简介

Claude 是由 Anthropic 公司开发的 AI 对话工具，由前 OpenAI 核心成员创立。Claude 以"安全性"和"可解释性"为核心设计理念，更适合处理敏感信息和企业应用。

2026 年，Claude 已更新到 3.5 Sonnet 版本，支持 200K token 上下文窗口，擅长长文本处理和复杂推理。

🚀 核心功能

1. 长文本处理

支持 200K token 上下文（约 15 万字），可一次性处理整本书籍、长篇报告。

2. 安全性更高

通过 Constitutional AI 训练，拒绝有害请求，更适合企业使用。

3. 多模态支持

支持图像输入，可分析图表、手写笔记、设计稿。

4. Artifacts 功能

实时生成代码、文档、图表，并在侧边栏显示，方便迭代修改。
